15/10/2026 - DESARROLLO DEL CASE B
------------------------------------------------------------

- Se completó el CASE B, encargado de gestionar la
  disponibilidad de fechas de las excursiones.
- Se utilizaron las funciones `fgetc()` y `fscanf()` para
  la lectura y el procesamiento de datos del archivo
  `excursiones.txt`.

  * `fgetc()`: permite leer un carácter de un flujo
    de entrada.
  * `fscanf()`: permite leer datos de un flujo de entrada
    utilizando un formato especificado.

- Estas funciones facilitaron la lectura del archivo
  y la búsqueda de coincidencias con los datos solicitados.

------------------------------------------------------------
16/10/2026 - DESARROLLO DEL CASE C

  evaluar el presupuesto y determinar qué excursiones
  se ajustan al rango económico indicado.
- Se utilizaron las variables `datos.presupuesto` y
  `datos.cant_personas` para calcular el presupuesto total
  disponible en función de la cantidad de personas y
  compararlo con el costo de las excursiones.
